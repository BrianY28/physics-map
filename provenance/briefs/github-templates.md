# Brief: GitHub issue forms and pull request template for the Physics Map repository

The repository (https://github.com/BrianY28/physics-map) is an open mind map of physics. Each node is a Markdown file `nodes/NN-branch/node-name.md` with front matter (order, when, people, status established|open, as_of for open nodes, sources, drafted_by, reviewed_by), a `# Title`, a 1-2 sentence note and a `## Concepts` list of 2-5 lines. Contribution guide: CONTRIBUTING.md. Branch folders: 01-newtonian-mechanics, 02-electromagnetism-optics, 03-thermodynamics-statmech, 04-quantum-mechanics-qft, 05-relativity-gravitation, 06-nuclear-particle, 07-amo-physics, 08-condensed-matter, 09-astrophysics-cosmology, 10-fluids-plasmas-complexity, 11-open-frontier.

Write these five files using GitHub's issue-form YAML syntax (name, description, title, labels, body with markdown / input / textarea / dropdown / checkboxes elements, `id` on every non-markdown element, `validations: required: true` where noted). Valid YAML only.

1. `.github/ISSUE_TEMPLATE/node-correction.yml`: name "Node correction", label `node-correction`, title prefix "[Correction] ". Fields: node file path or title (input, required); what is wrong (textarea, required); suggested correction (textarea, required); source that supports the correction (textarea, required, ask for a full citation); checkbox "I checked the source myself" (required).
2. `.github/ISSUE_TEMPLATE/new-node.yml`: name "New node", label `new-node`, title prefix "[New node] ". Fields: proposed title (input, required, max 7 words); branch (dropdown of the 11 folder names above, required); why it belongs in the map (textarea, required); draft note, 1-2 sentences (textarea); 2-5 concepts, one per line (textarea); sources (textarea, required); checkbox "I searched the map and this topic is not already covered" (required).
3. `.github/ISSUE_TEMPLATE/frontier-update.yml`: name "Frontier update", labels `frontier-update`, title prefix "[Frontier] ". Fields: which open node (input, required); what changed and when (textarea, required); source for the new result (textarea, required, peer-reviewed paper or collaboration paper preferred; press releases only alongside); dropdown "Does this settle the question?" with options "No, it updates the status", "Yes, the question is settled", "Not sure" (required).
4. `.github/ISSUE_TEMPLATE/config.yml`: allow blank issues; one contact link named "Contribution guide" pointing to https://github.com/BrianY28/physics-map/blob/main/CONTRIBUTING.md with a one-line about.
5. `.github/pull_request_template.md`: a short summary prompt, then a checklist: one topic per pull request; every new or changed claim has a source in `sources`; `as_of` updated for changed open nodes; `python3 tools/build.py --check` passes locally (GitHub also runs it); AI-assisted text is disclosed in `drafted_by` and checked by me against the sources; I agree that my contribution is licensed under CC BY-SA 4.0 (content) or MIT (code).

Plain, direct wording; no emoji.
